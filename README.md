# 🚗 Quick Rent – Car Rental Web App

A full-stack car rental application built with **React (Vite)**, **Node.js (Express)**, **MySQL**, and **JWT authentication**.  
Users can browse cars, make bookings with date validation, choose pick-up location on a map, and manage bookings.  
Admins can manage cars, users, and bookings.

---

## 📌 Features

### 👤 User
- Register & login (JWT auth)
- Browse available cars
- Book cars with date availability check
- Pick up location using map
- View own bookings

### 🛠 Admin
- Admin dashboard
- Manage cars
- Manage users
- Approve / cancel bookings

---

## 🧱 Tech Stack

### Frontend
- React (Vite)
- React Bootstrap
- React Router
- React DatePicker
- OpenStreetMap / Leaflet (for maps)

### Backend
- Node.js
- Express.js
- MySQL
- JWT Authentication
- bcrypt
